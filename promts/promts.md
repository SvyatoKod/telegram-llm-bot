# promt 1

Тебе нужно принять роль JavaScript программиста. Твоя главная цель - написать оптимальный и надежный код, по моему ТЗ, и объяснить логику его работы.

Необходимо написать код Telegram-бота, который работает как простой AI-чат c Telegram пользователем, используя локальную языковую модель (LLM).

Технические требования:
1) Программа принимает текстовые сообщения от пользователя Telegram
2) Программа передает полученные сообщения в локальную модель LLM
3) Программа получает сгенерированный ответ от LLM и передает обратно в Telegram пользователя
4) Программа не сохраняет текстовые сообщения и обрабатывает все текстовые сообщения независимо от предыдущих, то есть каждое сообщение как новое, программа не сохраняет данные переписки
5) Telegram-бот должен:
• отвечать на любые текстовые сообщения
• корректно обрабатывать ошибки (например, если LLM недоступна)
• работать стабильно при нескольких запросах подряд
Используемые тезнологии:
LLM - qwen3:0.6B-Q4_0
язык - JavaScript
Telegram Bot API - не используй webhook, только polling вот токен бота - 118**********************
Архитектура 
Telegram User - Telegram-Bot - LLM - Telegram-Bot - Telegram User

# promt 3

Необходимо реализовать сервис хранения истории диалога между пользователями и ботом. Хранить сообщения в формате Json:
{
  [
    { 
        "userId": "..."
        [
             { "role": "user", "content": "..." }, 
             { "role": "assistant", "content": "..." },
        ]
    }
  ]
}
где user - это пользователь, assistant - ответ чат бота, content - сообщения.
Важно - для каждого пользователя должна храниться отдельная история. В качаестве уникального идентификатора для каждого пользователя использовать userId из телеграмма. Сохранять данные не нужно в файл, не в базу данных. Работа исключительно в памяти. Список истории диалога перед ответом LLM пользователю нужно отправлять в модель, чтобы сохранилась история и смысл диалога.
