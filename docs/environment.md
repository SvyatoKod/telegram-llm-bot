## Настройки окружения

Переменные окружения можно задать через файл `.env` в корне проекта или через окружение процесса.

### Обязательные

- **`TELEGRAM_BOT_TOKEN`**: токен Telegram-бота.
  - **По умолчанию**: нет (обязателен)
  - **Пример**: `123456:ABCDEF...`

### Telegram

- **`TELEGRAM_POLL_TIMEOUT_SEC`**: long-poll timeout в секундах на стороне Telegram.
  - **По умолчанию**: `30`
  - **Диапазон**: `1..60`

### Ollama / LLM

- **`OLLAMA_URL`**: адрес Ollama API.
  - **По умолчанию**: `http://127.0.0.1:11434`
- **`OLLAMA_MODEL`**: имя модели Ollama.
  - **По умолчанию**: `qwen3:0.6b`
- **`SYSTEM_PROMPT`**: системная инструкция, задающая поведение модели (всегда идёт первым сообщением в контексте).
  - **По умолчанию**:  
    `Ты пионер вожатый, который приветствует и говорит с другими пионерами. Ты хочешь помочь другим и, если не знаешь ответ, то говоришь "Я не знаю товарищ".`

### Runtime

- **`MAX_CONCURRENCY`**: максимальное число параллельных обработок (и запросов в LLM).
  - **По умолчанию**: `4`
  - **Диапазон**: `1..32`

### История диалога (in-memory)

- **`COUNT_MESSAGE_LIMIT`**: лимит сообщений в истории на пользователя (user+assistant суммарно). При превышении удаляются самые старые.
  - **По умолчанию**: `10`
  - **Диапазон**: `1..500`
- **`COUNT_MESSAGE_SUMMARY_LIMIT`**: порог, после которого включается сжатие истории (саммари).
  - **По умолчанию**: `6`
  - **Диапазон**: `2..500`

## Пример `.env`

```bash
TELEGRAM_BOT_TOKEN=xxx:yyyy
OLLAMA_URL=http://127.0.0.1:11434
OLLAMA_MODEL=qwen3:0.6b

TELEGRAM_POLL_TIMEOUT_SEC=30
MAX_CONCURRENCY=4

COUNT_MESSAGE_LIMIT=10
COUNT_MESSAGE_SUMMARY_LIMIT=6

SYSTEM_PROMPT=Ты пионер вожатый, который приветствует и говорит с другими пионерами. Ты хочешь помочь другим и, если не знаешь ответ, то говоришь "Я не знаю товарищ".
```
